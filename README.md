# DeskPing

**安静待在右下角，到点时用力叫醒你的 Windows 计时提醒器。**

正计时 / 倒计时 / 目标时刻，托盘常驻、置顶、自由缩放，纸张质感界面，功耗极低。

![platform](https://img.shields.io/badge/platform-Windows%20x64-555) ![.NET](https://img.shields.io/badge/.NET-10-512bd4)

## 功能

| 模式 | 说明 |
| :--- | :--- |
| **正计时** | 从零开始累计，适合专注时长、通勤、健身等 |
| **倒计时** | 设定时长（时:分:秒输入 + `+5分` `+15分` `+30分` 快捷累加），归零即提醒 |
| **目标时刻** | 设定时刻（今天 / 明天 / 自定义日期），到点提醒；支持**每日重复**（到点后自动顺延一天） |

### 到点提醒（多重保险，不会错过）

- 窗口自动弹出置顶，数字**上下跳动**，边框**呼吸闪动**
- **任务栏图标闪烁** + 提示音（可关）+ 托盘气泡
- 点「知道了」停止动画并复位

### 窗口与托盘

- **托盘常驻**：双击图标显示 / 隐藏，右键菜单退出
- **置顶**：标题栏图钉按钮或托盘菜单，可让纸片一直浮在其他窗口之上
- **自由缩放**：拖动窗口边角即可放大缩小，数字随窗口自动缩放
- **点击输入框自动全选**，直接输入新数字覆盖
- **× 只是藏进托盘**，不退出；设置自动保存，重启恢复（位置、大小、主题、模式）

## 功耗设计

- 计时核心只有一个 **1Hz 节拍器**，每秒一次比较，空闲 CPU ≈ 0%，无忙轮询
- 窗口隐藏时**零 UI 刷新**；跳动动画仅提醒期间运行，确认即停
- 全部界面 GDI+ 按需自绘，无常驻渲染管线；常驻内存约 30MB 级

## 使用

1. 运行 `DeskPing.exe`（见下文构建），纸片出现在屏幕右下角。
2. 右键托盘图标可切换模式、主题（暖纸 / 墨 / 林 / 霞 + 深色）、置顶、提醒音、开机自启、退出。
3. 设置保存在 `%APPDATA%\DeskPing\settings.json`。

## 构建

需要 [.NET 10 SDK](https://dotnet.microsoft.com/download)。

```sh
dotnet build -c Release
```

| 脚本 | 产物 | 说明 |
| :--- | :--- | :--- |
| `publish.cmd` | `publish\DeskPing.exe` | 约 300KB，需目标机器装有 .NET 10 桌面运行时 |
| `publish-self-contained.cmd` | `publish-self-contained\DeskPing.exe` | 自带运行时，免安装，约 60MB |
