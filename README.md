# DeskPing

<div align="right">**简体中文** · [English](README.en.md)</div>

**安静待在右下角，到点时用力叫醒你的 Windows 计时提醒器。**

正计时 / 倒计时 / 目标时刻，托盘常驻、置顶、自由缩放，纸张质感界面，功耗极低。

## 功能

| 模式 | 说明 |
| :--- | :--- |
| **正计时** | 从零开始累计，适合专注时长、通勤、健身等 |
| **倒计时** | 设定时长（时:分:秒直接输入），归零即提醒 |
| **目标时刻** | 设定时刻（今天 / 明天 / 自定义日期），到点提醒；支持**每日重复**（到点后自动顺延一天） |

三种模式下方都有一个**备注框**：随时可以点进去写一句话（例如“喝水”“午休 20 分钟”），不输入时文字居中、弱化显示。开始计时后，备注作为“正在做什么”的提示显示在数字下方；到点提醒时随气泡和提醒画面一起显示。

> 开始计时后设置区自动收起，只显示时间，点「重置」恢复。会话内容（备注 / 时长 / 目标）不保存，每次打开都是全新计时。

### 到点提醒（多重提醒，不容错过）

- 窗口自动弹出置顶，数字**上下跳动**，边框**呼吸闪动**
- **任务栏图标闪烁** + 提示音（可关）+ 托盘气泡
- 点「知道了」停止动画并复位

### 窗口与托盘

- **托盘常驻**：双击图标显示 / 隐藏，右键菜单退出
- **置顶**：标题栏图钉按钮或托盘菜单
- **自由缩放**：拖动窗口边角即可放大缩小，数字随窗口自动缩放
- **点击输入框自动全选**，直接输入新数字覆盖；再点一次光标落在点击处
- **× 只是藏进托盘**，不退出；应用设置自动保存，会话内容（备注 / 时长）每次打开重置

### 语言

应用默认中文，可在托盘菜单「语言」中切换为 English，即时生效并保存。

## 功耗设计

- 计时核心只有一个 **1Hz 节拍器**，每秒一次比较，空闲 CPU ≈ 0%，无忙轮询
- 窗口隐藏时**零 UI 刷新**；跳动动画仅提醒期间运行，确认即停
- 全部界面 GDI+ 按需自绘，无常驻渲染管线

## 使用

1. 运行 `DeskPing.exe`，纸片出现在屏幕右下角。
2. 右键托盘图标可切换模式、语言、主题（暖纸 / 墨 / 林 / 霞 + 深色）、置顶、提醒音、开机自启、退出。
3. 设置保存在 `%APPDATA%\DeskPing\settings.json`。

## 构建

需要 [.NET 10 SDK](https://dotnet.microsoft.com/download)。

```sh
dotnet build -c Release
```

| 脚本 | 产物 | 说明 |
| :--- | :--- | :--- |
| `publish.cmd` | `publish\DeskPing.exe` | 约 300KB，需目标机器装有 .NET 10 桌面运行时 |
| `publish-self-contained.cmd` | `publish-self-contained\DeskPing.exe` | 自带运行时，免安装，约 60MB |
